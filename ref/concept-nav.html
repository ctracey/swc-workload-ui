NAV ICONS

THEME · REV·2

Four navigation glyphs in the MONOLITH hazard-panel language — 24-grid, 2px hard strokes, square caps, single yellow accent. Click a rail item to preview the active (dark-on-yellow) state.

Usage. Each SVG paints from currentColor for structure, so set the icon colour via CSS color. The yellow accent is fixed at #ffd400 (class .acc / .accs) — override those to currentColor inside an active/selected tile to get the dark-on-yellow look shown in the chips.
